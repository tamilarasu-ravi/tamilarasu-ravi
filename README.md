## Featured Work

### Transaction Auto-Tagging Agent

Safety-first finance pipeline: deterministic vendor rules → LLM classification with multi-provider fallback → confidence routing → human-in-the-loop review that promotes corrections into rules.

- **100%** auto-tag precision on eval fixtures · **zero** silent miscodings
- Targets **60%+** safe automation and cutting month-end close from ~7 days to 2–3 days

[View source](https://github.com/tamilarasu-ravi/auto-tagging-agent)

---

### ReconAI — CFO Operations Platform

TypeScript/Next.js evolution of safety-first close automation: one **orchestrator** runs policy, tagging, and payables; agents return structured decisions only; Postgres + pgvector is the system of record.

- Tri-state autonomy (`AUTO_TAG` · `QUEUE_REVIEW` · `REFUSE`) — **100%** eval pass rate, **100%** auto-tag precision @ 0.92 on held-out set
- Rule-first routing, receipt gates, HITL review loop, vendor-rule learning, and full audit replay

[Live demo](https://recon-ai-ivory.vercel.app/)

---

### Eliza AI — Production RAG Recommendation Engine

End-to-end LLM recommendation system replacing rigid rules with contextual retrieval (PGVector), prompt engineering, and real-time inference at scale.

- Serves **5K+** daily active users with measurable engagement lift
- Rearchitected LLM orchestration layer — **35%** faster end-to-end response time

---

### AI API Orchestration Layer

Microservices redesign for multi-team LLM routing, async pipelines, and response caching across a real-time AI platform.

- **35%** improvement in end-to-end system response time
- Unblocked multiple product teams to ship AI features in parallel
